BadgeFarm Samples

A tiny demo project to practice GitHub actions that earn community badges fast.

What’s inside

  • Two example feature branches and two PRs (you will create)
  • Sample issues for Quickdraw badge
  • Co-authored commit example for Pair Extraordinaire
  • Discussion templates to post on GitHub Discussions for Galaxy Brain

Quick commands

# create branch
git checkout -b fix-1
# edit README or a file, commit
git add .
git commit -m "tiny fix #1"
git push -u origin fix-1

See README.md for full steps.
