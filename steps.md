# Quick Steps to Earn Each Badge (manual + automated hints)

> Do these steps in this repo. Replace USERNAME below with your GitHub username.

---

## 0. Setup (create the repo)
1. Create a **new public repo** on GitHub.
2. Name it something attractive (if this is for profile README, name must be **your username**).
3. Clone locally, add the files from this project, push to `main`.

---

## 1. Pull Shark (merge 2 PRs)
Manual:
1. Create branch `fix-1`, make a trivial change (README typo), commit & push.
2. Create branch `fix-2`, commit & push.
3. Open **two pull requests** toward `main` from `fix-1` and `fix-2`.
4. Merge both PRs (you can merge them yourself).
Result: merges = Pull Shark badge.
