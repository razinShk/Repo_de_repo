# BadgeFarm Samples

Simple repo to practice GitHub activities which help earn badges like:
- Pull Shark (merge 2 PRs)
- YOLO (merge a PR without waiting for review)
- Quickdraw (close issue/PR within 5 minutes)
- Pair Extraordinaire (co-authored merged PR)
- Galaxy Brain (2 accepted answers on Discussions)
- Starstruck (get 16 stars)
- Public Sponsor (sponsor someone)

> Follow the `STEPS.md` for step-by-step guides and automation scripts.
